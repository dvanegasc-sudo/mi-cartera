# Mi Cartera

App para anotar gastos e ingresos desde el celular, también por voz (con el micrófono del teclado).

- Pestañas **Personal** y **Trabajo** (obras de construcción).
- Bolsillos **Efectivo**, **Nequi** y **Tarjeta**, cada uno con su propio saldo, y balance general.
- Traslados entre bolsillos, notas, informes por día y por mes en PDF y Excel.
- Los datos se guardan **solo en el celular** de quien la usa. Nadie más los ve.
- Funciona sin internet. Se instala con "Agregar a pantalla de inicio".
- Botón **💾 Copia** para guardar una copia de seguridad y **Cargar copia** para recuperarla.
